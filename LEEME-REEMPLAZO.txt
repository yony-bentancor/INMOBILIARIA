QCASA - ACTUALIZACIÓN LECTOR QR

ARCHIVOS PARA REEMPLAZAR
========================
1) routes/index.js
2) views/index.njk
3) public/css/style.css

ARCHIVOS NUEVOS PARA AGREGAR
============================
4) views/qr.njk
5) public/js/qr-scanner.js

CÓMO INSTALAR
=============
Copiá el contenido de esta carpeta sobre tu proyecto respetando exactamente las carpetas.
Cuando Windows pregunte si querés reemplazar archivos, elegí "Reemplazar".

Después ejecutá:

npm install
npm run dev

Probá:
http://localhost:3000/qr

También podés entrar al index y tocar "Escanear QR".

FUNCIONES NUEVAS
================
- Botón protagonista "Escanear QR" en el index.
- Nueva pantalla /qr.
- Abrir cámara tras permiso del usuario.
- Lectura automática del QR cuando el navegador soporta BarcodeDetector.
- Opción "Tomar foto del QR".
- Código manual como respaldo.
- QR QCASA con URL /r/AB123X redirige directamente al reclamo.
- Un código simple como AB123X también funciona.

IMPORTANTE
==========
La cámara del navegador funciona en localhost y, en producción, requiere HTTPS.
Heroku utiliza HTTPS, por lo que esto queda preparado para desplegar.
